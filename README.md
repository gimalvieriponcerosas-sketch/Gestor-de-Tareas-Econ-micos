# Gestor de Tareas Académicas - Equipo

## Descripción
Aplicación web para organizar las tareas académicas de un aula. Permite registrar una tarea con título y responsable, mostrar la lista, marcar tareas como completadas y eliminarlas. Los datos se mantienen en memoria.

Proyecto del curso **Seminario Complementario II (SENATI)**, desarrollado de forma colaborativa con Git y GitHub.

## Instrucciones de ejecución
1. Clonar el repositorio:
```
   git clone https://github.com/gimalvieriponcerosas-sketch/Gestor-de-Tareas-Econ-micos.git
```
2. Entrar a la carpeta del proyecto:
```
   cd Gestor-de-Tareas-Econ-micos
```
3. Abrir la carpeta en Visual Studio Code.
4. Abrir el archivo `index.html` en el navegador (doble clic o con la extensión Live Server).

## Funcionalidades
- Registrar tareas con título y responsable
- Listar tareas
- Marcar tareas como completadas
- Eliminar tareas

## Organización del trabajo
Cada integrante trabaja en ramas propias con el formato `feature/<nombre>-<funcionalidad>` y los cambios se integran a `main` mediante Pull Requests revisados por otro integrante.

## Estrategia de ramas
- `main`: versión estable y funcional.
- `feature/*`: una rama por funcionalidad, que se integra a `main` por Pull Request.
